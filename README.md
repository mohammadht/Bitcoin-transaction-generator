# Bitcoin-transaction-generator

## Prerequisites
Before running this application, make sure you have the following installed:

Python: Ensure you have Python 3 installed on your system. You can download it from here.

Required Python Packages: The following Python libraries are required:

tkinter (for the graphical user interface)
time (for time-related functions)
threading (for multi-threading)
hashlib (for hashing algorithms)
string (for string manipulation)
os (for interacting with the operating system)
pandas (for data manipulation and analysis)
numpy (for numerical computations)
json (for handling JSON data)
random (for generating random numbers)
scipy (for statistical distributions)

You can simply install the libraries by running the following command in the project directory:

pip install -r requirements.txt

## Run the application:
### On windows:
python bitcoin-generator.py
### On Mac/Linux:
python3 bitcoin-generator.py
